# Чайный двор

Многостраничный учебный сайт интернет-магазина листового чая. Контрольная работа №1 по дисциплине «Фронтенд и бэкенд разработка».

Сайт: https://shebaketerayo.github.io/kr1-html-css-shop-gorbunov/

## Страницы

| Файл | Что на странице |
|---|---|
| `index.html` | главная: о магазине, преимущества, хиты сезона |
| `catalog.html` | каталог из четырёх чаёв |
| `product-oolong.html`, `product-puer.html`, `product-sencha.html`, `product-jasmine.html` | страницы чаёв с характеристиками и способом заваривания |
| `order.html` | форма заявки |
| `contacts.html` | адрес, телефон и часы работы |

Стили лежат в `css/style.css`, скрипт модального окна и формы — в `js/main.js`, картинки — в `images/`.

## Технологии

HTML5, CSS3 (Flexbox, Grid, БЭМ), JavaScript.

## Постановка контрольной работы №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Нужно сделать многостраничный сайт интернет-магазина или каталога услуг. В нём должны быть:

- главная страница;
- каталог;
- страница товара;
- страница оформления заявки;
- страница контактов;
- семантическая разметка и общий внешний CSS-файл;
- навигация между страницами.

## Ход работы

- ПР1 — репозиторий, первые коммиты, ветка и Pull Request, публикация на GitHub Pages.
- ПР2 — стартовая страница: семантические блоки, меню, hero-блок, преимущества, хиты сезона, aside; базовые стили.
- ПР3 — кнопки «Заказать», модальное окно с формой заявки, HTML-валидация и обработка отправки на JavaScript.
- КР №1 — каталог, страницы четырёх чаёв, страница заявки и контакты; адаптивная вёрстка на Flexbox и Grid.
