# Чайный двор

Учебный frontend-проект по дисциплине «Фронтенд и бэкенд разработка». В течение семестра здесь появится многостраничный сайт интернет-магазина листового чая.

## Структура

- `index.html` — стартовая страница;
- `css/style.css` — стили;
- `js/main.js` — модальное окно и проверка формы;
- `images/` — изображения;
- `.gitignore` — исключения для Git;
- `README.md` — описание проекта.

## Технологии

HTML, CSS, JavaScript, Git, GitHub.

## Постановка контрольной работы №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Нужно сделать многостраничный сайт интернет-магазина или каталога услуг. В нём должны быть:

- главная страница;
- каталог;
- страница товара;
- страница оформления заявки;
- страница контактов;
- семантическая разметка и общий внешний CSS-файл;
- навигация между страницами.

## Ход работы

- ПР1 — репозиторий, первые коммиты, ветка и Pull Request, публикация на GitHub Pages.
- ПР2 — стартовая страница: семантические блоки, меню, hero-блок, преимущества, хиты сезона, aside; базовые стили.
- ПР3 — кнопки «Заказать», модальное окно с формой заявки, HTML-валидация и обработка отправки на JavaScript.
