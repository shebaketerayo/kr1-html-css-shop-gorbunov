# Чайный двор

Учебный frontend-проект по дисциплине «Фронтенд и бэкенд разработка». В течение семестра здесь появится многостраничный сайт интернет-магазина листового чая.

## Структура

- `index.html` — стартовая страница;
- `css/style.css` — стили;
- `images/` — изображения;
- `.gitignore` — исключения для Git;
- `README.md` — описание проекта.

## Технологии

HTML, CSS, Git, GitHub.
